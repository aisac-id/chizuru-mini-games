# SECURITY & TAKEDOWN — `aisac-id/chizuru-mini-games`

## Takedown hak kekayaan intelektual / IP takedown

Proyek ini adalah karya fan-made tidak resmi dan non-komersial. Karakter
Chizuru Mizuhara dan Rent-A-Girlfriend © Reiji Miyajima/Kodansha (lihat
`NOTICE.md`).

- **Kanal resmi:** buka [GitHub Issue](https://github.com/aisac-id/chizuru-mini-games/issues)
  di repositori ini dengan judul berisi kata "Takedown". Sertakan identitas
  pemegang hak/kuasa dan konten yang diminta turun.
- **Target respons: 24–48 jam.** Konten yang diminta akan dihapus secepatnya
  dari repositori dan halaman GitHub Pages.
- Tanpa perlu email; seluruh proses tercatat publik di issue repositori.

This is an unofficial, non-commercial fan-made project. Rights holders who
want content removed should open a **GitHub Issue** titled "Takedown" in
this repository, identifying the rights holder and the content concerned.
**Response target: 24–48 hours**; requested content will be taken down
promptly from the repository and GitHub Pages.

## Laporan kerentanan keamanan / Security vulnerability reports

Game ini HTML statis tanpa server, tanpa akun, dan tanpa pengumpulan data
pribadi (progres hanya di localStorage browser).

- Laporkan kerentanan lewat **GitHub Issue** dengan judul "Security".
  **Jangan** menyertakan detail eksploit, payload, atau data pihak ketiga
  di issue publik — cukup deskripsi umum; maintainer akan menindaklanjuti.
- Target respons: **24–48 jam**.
- Report vulnerabilities via a **GitHub Issue** titled "Security" with a
  general description only — no exploit details in public. Response
  target: **24–48 hours**.
